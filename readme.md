# 🤖🚀 Projeto Vibe Coding — Sistema Multiagente de Orientação de Carreira em Tecnologia

Este projeto demonstra como utilizar **Vibe Coding** para criar um sistema conceitual de **IA Multiagente** capaz de:

- Entender o perfil de uma pessoa interessada em tecnologia  
- Sugerir carreiras adequadas  
- Gerar planos de estudos personalizados  

Tudo isso **sem escrever código**, utilizando apenas prompts bem estruturados e raciocínio de produto.

---

## 🧠 O que é Vibe Coding?

Vibe Coding é uma abordagem de desenvolvimento baseada em:

- Comunicação clara com IA  
- Definição de contexto e intenção  
- Estruturação de prompts como especificações de produto  

> Você mostra a vibe da ideia. A IA ajuda a transformar em solução.

---

## 🎯 Objetivo do Projeto

Criar um **sistema de dois agentes de IA** que trabalham juntos:

1. Um agente entrevista o usuário  
2. Outro agente monta um plano de estudos completo  

Simulando como seria um produto real de orientação de carreira.

---

## 🧩 Estrutura do Sistema

```
📦 projeto
┣ 📄 AGENT 1 - Entrevistador de Carreira.md
┣ 📄 AGENT 2 - Especialista em Plano de Estudos.md
┗ 📄 README.md
```

---

## 🤖 AGENT 1 — Entrevistador de Carreira

Responsável por:

- Fazer 7 perguntas estruturadas  
- Entender interesses, experiência e objetivos  
- Sugerir 3 carreiras ranqueadas  
- Transferir os dados para o Agent 2  

### Saída do Agent 1
- Carreira escolhida  
- Horas semanais  
- Nível de experiência  
- Objetivo  
- Preferência (pessoas/dados/código)  
- Interesses técnicos  

---

## 🧠 AGENT 2 — Especialista em Plano de Estudos

Responsável por:

- Criar visão do dia a dia da carreira  
- Mapear skills essenciais  
- Gerar roadmap de 90 dias  
- Propor projeto de portfólio  
- Criar roteiro de entrevistas  
- Indicar trilhas de estudo  

---

## 🔄 Fluxo de Funcionamento

- Usuário → Agent 1 → Escolha de carreira → Agent 2 → Plano personalizado
---

## 📌 Exemplo de Uso

1. Abra o arquivo do Agent 1  
2. Inicie a entrevista  
3. Responda às 7 perguntas  
4. Escolha uma carreira sugerida  
5. Envie os dados para o Agent 2  
6. Receba seu plano de estudos
